# 🎾 양벌 테니스 돔 빈 코트 찾기

광주시 양벌 테니스 돔 12개 코트의 예약 현황을 **날짜 기준으로 한 번에** 보여주는 웹앱입니다.
기획 내용은 [PLAN.md](PLAN.md) 참고.

- 달력: 한 코트라도 비어 있으면 🟢(예약가능) / 🟡(빈자리지만 아직 신청기간 아님)으로 표시하고 빈 시간대(예: `6·8·20시`)를 보여줌
- 날짜 클릭: 시간대별로 비어있는 코트 목록 + `코트 × 시간` 전체 표
- 휴대폰에서 "홈 화면에 추가" 하면 앱처럼 사용 가능

## 내 PC에서 실행
```powershell
python server.py
```
→ 브라우저에서 http://localhost:8000

같은 와이파이의 휴대폰에서는 `http://<PC의 IP>:8000` 으로 접속 (Windows 방화벽 허용 필요).

## 예약 오픈일 예측 · 자동 검증 (`opening.py`)
- 현재 가설: **해당 월 1일에 그 달 온라인 수시대관 오픈**, **사용 3일 전까지 신청**
- 서버가 켜져 있으면 사이트를 1시간마다 관측합니다. 예상일 전날부터는 10분마다 관측합니다. 결과는 `state/`에 저장됩니다.
- 예상일이 지나 실제로 열린 시점의 범위 `[마지막으로 닫혀 있던 시각 ~ 처음 열린 시각]`을 예상일과 비교합니다.
  - **확정**: 예상일 당일에 열렸고, 전날 18시 이후(또는 당일)에 닫혀 있던 것을 확인함
  - **일치(범위 넓음)**: 모순은 없지만 관측 간격이 넓어서 날짜를 확정하지 못함
  - **틀림**: 실제 오픈일로 새 규칙을 학습합니다 (예: "해당 월 3일" 또는 "전월 28일"). 다음 달에 다시 검증합니다.
- 서버를 켜지 않고 한 번만 관측하려면 아래 명령을 실행하세요 (Windows 작업 스케줄러에 등록해도 됩니다).
  ```powershell
  python server.py --observe
  ```

## 어디서든 접속하기 (배포)
코드를 GitHub 저장소에 올린 뒤 아래 중 하나를 고르세요.

### 방법 A. Render.com (실시간 조회, 추천)
1. https://render.com 가입 → **New + → Blueprint** → 이 GitHub 저장소 선택
2. `render.yaml`이 자동 인식되어 배포됨 → `https://yangbeol-court-xxxx.onrender.com` 주소 발급
- 무료 플랜은 15분간 접속이 없으면 잠들어서, 첫 접속 시 30~50초 걸릴 수 있음

### 방법 B. GitHub Pages (서버 없음, 10분 간격 갱신)
1. 저장소 **Settings → Pages → Source: GitHub Actions** 선택
2. `.github/workflows/pages.yml`의 `schedule` 주석을 풀면 10분마다 데이터를 받아 `https://<아이디>.github.io/<저장소>/` 에 게시
- 항상 빠르게 열리지만 데이터가 최대 10~20분 늦을 수 있음

> ⚠️ Render·GitHub 서버는 해외에 있습니다. 예약 사이트가 해외 접속을 막으면 조회가 실패하는데,
> 그 경우 집 PC에서 `python server.py`를 켜두고 Tailscale이나 Cloudflare Tunnel로 외부에서 접속하세요.

## 구조
| 파일 | 역할 |
|------|------|
| `server.py` | 예약 사이트 공개 API에서 12개 코트 데이터를 모아 날짜별로 합침 (`/api/month?ym=YYYYMM`, 3분 캐시) |
| `public/` | 화면 (HTML/CSS/JS) |
| `render.yaml` | Render 배포 설정 |
| `.github/workflows/pages.yml` | GitHub Pages 자동 갱신 배포 |
