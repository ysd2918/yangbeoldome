# 🎾 양벌 테니스 돔 빈 코트 찾기

광주시 양벌 테니스 돔 12개 코트의 예약 현황을 **날짜 기준으로 한 번에** 보여주는 웹앱입니다. 집 PC에서만 실행합니다.
기획 내용은 [PLAN.md](PLAN.md)에 있습니다.

- **달력:** 한 코트라도 온라인으로 예약할 수 있으면 🟢로 표시하고, 빈 시간대(예: `6·8·20시`)도 함께 보여줍니다.
- **날짜 클릭:** 시간대별로 비어 있는 코트 목록과 `코트 × 시간` 전체 표가 나옵니다.
- **예약 오픈 예상일:** 예상 오픈일을 보여주고, 실제로 열렸는지 자동으로 검증합니다.

## 실행
**`실행.bat`을 더블클릭**하면 됩니다.
- 서버가 켜지고 브라우저에서 http://localhost:8765 가 자동으로 열립니다.
- 검은 창을 닫으면 종료됩니다.
- 이미 켜져 있을 때 다시 더블클릭하면 브라우저만 열립니다.

명령어로 실행하려면 다음을 입력하세요.
```powershell
python server.py --open
```

> 예약 사이트가 해외 서버에서 오는 접속을 막기 때문에 Render 같은 해외 클라우드에서는 동작하지 않습니다. 한국에 있는 PC에서 실행해야 합니다.

## 예약 오픈일 예측 · 자동 검증 (`opening.py`)
- **현재 규칙 (11/28 관측):** 날짜마다 **사용일 3일 전에 하루만** 온라인 신청이 열립니다. 예를 들어 11/28에는 12/1만 열렸습니다.
  - 처음에 세운 "달 전체가 1일에 열림" 가설은 틀린 것으로 확인돼 버렸습니다.
- **달력 표시:** 아직 안 열린 날짜에는 예상 오픈일(예: `11/29 오픈`)이 나옵니다.
- **관측 주기:** 서버가 켜져 있으면 30분마다 사이트를 확인합니다. 기록은 `state/` 폴더에 저장됩니다.
- **검증 방법:** 관측할 때마다 "지금 열린 날짜"를 규칙으로 계산한 날짜와 비교합니다.
  - **확정:** 서로 다른 2일 이상에 걸쳐 3번 맞으면 확정합니다.
  - **새 규칙:** 같은 불일치가 2번 연속 나오면 실제 열린 범위(예: "사용일 10일 전 ~ 3일 전")로 규칙을 바꿉니다. 한 번만 어긋난 건 날짜가 바뀌는 순간에 관측한 것일 수 있어서 무시합니다.
  - **오픈 시각:** 각 날짜가 닫힘에서 열림으로 바뀐 시각 범위를 모아 점점 좁혀 갑니다.
- **서버 없이 한 번만 확인하려면:** 아래 명령을 실행하세요.
  ```powershell
  python server.py --observe
  ```

## 구조
| 파일 | 역할 |
|------|------|
| `실행.bat` | 더블클릭 실행 |
| `server.py` | 예약 사이트의 공개 데이터에서 12개 코트 현황을 모아 날짜별로 합침 (`/api/month`, 3분 캐시), 접속 진단 (`/api/diag`) |
| `opening.py` | 예약 오픈일 예측·관측·규칙 학습 |
| `public/` | 화면 (HTML/CSS/JS) |
